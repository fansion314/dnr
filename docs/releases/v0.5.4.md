# DNR v0.5.4

The runtime remains pinned to Deno v2.9.8 (`fe7ed012d9`) and Laufey `1fe8787`.
DNP format remains v4.

`dnr --version` now reads Deno's compiled version constant instead of a separate
hardcoded string. The v0.5.3 runtime used the correct Deno v2.9.8 source but
reported Deno 2.9.7 in this banner. Arch and macOS release checks now compare
the banner against the pinned upstream version file before packaging.

The v0.5.3 tag and published assets remain unchanged. This release includes the
same upstream fixes and integration patches, with corrected version reporting.
Native compilation and runtime/package checks run in GitHub Actions.
