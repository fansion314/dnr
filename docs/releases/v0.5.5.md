# DNR v0.5.5

The runtime remains pinned to Deno v2.9.8 (`fe7ed012d9`) and Laufey v0.7.0
(`1fe8787`). DNP format remains v4; no application JavaScript API or Laufey C ABI
changes are required.

- Prepare upstream sources from pinned Git snapshots and record their provenance.
  Builds reject stale or modified prepared trees before synchronizing integration
  files. Re-preparing preserves the previous tree for debugging.
- Keep recursive copies consistent with ZIP reads on macOS by disabling native
  directory cloning for filesystems with a VFS overlay.
- Bound persistent-cache index synchronization on application exit to 100 ms,
  including queue admission. Explicit cache-management synchronization has a
  separate bounded deadline.
- Continue observing saved binding contexts after their calls finish, so document
  invalidation aborts their signals. The watcher does not keep the runtime alive.
- Skip directories and non-executable package entries during PATH searches while
  retaining native-group, platform and integrity checks for selected executables.
- Move cold asynchronous ZIP decompression and integrity checks to the blocking
  task pool, preserving shared loads, resident-cache reads and file positions.

Regression coverage includes VFS copies and corrupt entries, PATH candidates,
cache-exit congestion, asynchronous reads and saved document contexts. A new
pull-request/manual workflow builds macOS and all three Linux backend variants.

Before release, native Linux x86_64 debug builds passed for dual, system-CEF and
WebView, together with workspace tests, strict Clippy, 27 runtime regressions and
four Node-API/FFI cases. Real Linux document-security fixtures passed for both
backends and the single-backend builds; WebView renderer-termination coverage
also passed. The CEF renderer-crash fixture remains unverified because it could
not identify a unique renderer process safely. macOS release builds and package
checks run in GitHub Actions; current-source WKWebView GUI acceptance was not
completed before this release commit.
