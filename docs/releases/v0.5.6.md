# DNR v0.5.6

Updates the versioned system-CEF API baseline from 14900 to 15400 for the
stable Arch CEF 154 package. `DNR_CEF_API_VERSION=15600` selects the latest
stable CEF 156 API for an explicit build against matching headers/libraries;
it does not enable Arch testing repositories for normal releases.

CEF wrapper, backend and ABI bridge now share one CMake API selection. Runtime
API hash checks and automatic WebView fallback remain enabled. Changing the
API environment variable invalidates the native build configuration.

Local preparation checks cover formatting and replay of the pinned Deno and
Laufey patches. Full builds and CEF 154/156 validation run in GitHub Actions;
manual GUI testing is not represented by these checks.
