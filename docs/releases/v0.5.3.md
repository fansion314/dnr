# DNR v0.5.3

The shared runtime now uses Deno v2.9.8 (`fe7ed012d9`). Laufey remains pinned
to `1fe8787`, and the application package format remains v4.

This update includes upstream fixes for V8 operation-context lifetime, Node-API
DataView bounds and pending exceptions, Node.js assertions and mock resets,
HTTP connection-pool cleanup, TLS trust, and patched random-number dependencies.

The rebased integration retains native-group module path mapping, read-only
ZIP behavior, persistent caches, application identity, and desktop lifecycle
hooks. Upstream dynamic-import and worker read-permission checks remain intact.

Before release, both integration patches passed forward/apply/reverse checks
against clean pinned Git snapshots. Native builds and runtime tests run in the
Arch and macOS release workflows; local compilation was not performed.
