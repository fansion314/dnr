# dnr v0.1.0

First release of the shared Deno runtime and lightweight application packager.

- Run local JavaScript/TypeScript and executable `.dnp` application packages.
- Package prepared code, dependencies and assets with `dnc`, without bundling a runtime.
- Read Zstd-compressed ZIP contents on demand through a read-only VFS with disk fallback.
- Load compatible packaged Node-API / FFI libraries from private temporary directories.
- Inspect and extract packages with `dnr tree` and `dnr extract`.
- Create thin macOS ARM64 `.app` bundles and Arch/CachyOS application packages from a desktop manifest.
- Use native desktop windows, bindings, trays and background tasks with coordinated application lifetime.

Supported targets: macOS ARM64 WebView; Linux x86_64 WebView and system CEF.
Applications run with full permissions. Modules must be prepared locally; online
npm/JSR/HTTP module resolution is not supported.

## Arch Linux / CachyOS

The source release includes two AUR recipes under `packaging/aur`:

- `dnr`: system CEF (default package).
- `dnr-webview`: WebKitGTK alternative, providing `dnr`.

Both contain `dnr` and `dnc` and cannot be installed together. They download
`https://github.com/fansion314/dnr.git` at `v0.1.0` and pin the Deno/Laufey inputs.
See `packaging/aur/README.md` for dependencies and `makepkg -si` instructions.
The recipes are included in this release; AUR registration is a separate step.

## Validation

The repository includes native macOS and Linux validation records. The latest
Linux validation covers both backends, 14 runtime/native tests per backend,
real GUI bindings, native close events and Arch desktop application packaging.
See `VALIDATION.md` for exact environments, commands and remaining coverage limits.

This is a source release. Build instructions are in the English and Chinese
READMEs. System GUI libraries remain external dependencies; no Chromium or Deno
runtime is bundled in application packages.

Original dnr code: MIT. Third-party licenses and pinned sources are listed in
`THIRD_PARTY.md`.
