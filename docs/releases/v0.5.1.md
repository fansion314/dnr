# DNR v0.5.1

Adds optional native document authority for applications that expose privileged
host operations. `BrowserWindow.documentPolicy` restricts documents and
redirects; `bindWithContext()` supplies native frame/origin/document identity
and an abort signal. Releasing or replacing a page revokes its pending calls.
Protected calls do not log arguments or results. CEF rejects child-frame calls
that borrow a parent's bridge function.

Adds background system lock/suspend/resume monitoring and idle-time capability
reporting. Security events cannot be dropped by a saturated ordinary input
queue. Applications retain responsibility for their lock policy and must
handle unavailable native monitoring explicitly.

DNP remains format 4. Applications not enabling document policy retain existing
window behavior. Details, limits and verification are in
[DOCUMENT-SECURITY.md](../DOCUMENT-SECURITY.md).

This runtime feature release does not mean the separate Bitwarden adaptation
has completed its integration or security acceptance tests.
