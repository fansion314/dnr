# dnr v0.3.1

The default Linux dual runtime now loads system GUI libraries only when a desktop
operation needs them. CLI scripts and HTTP services can run without installing
CEF, WebKitGTK or GTK. DNP format v3 and existing v3 applications remain compatible.

## Backend loading

- Only `dual` builds use lazy imports. CEF-only and WebView-only builds retain
  direct linking and mandatory dependencies on their selected backend.
- Auto mode prefers CEF and falls back to WebView when CEF libraries, ABI/resource
  checks or initialization fail. Explicit selection reports the error without
  switching backends. An initialized application is never replayed.
- CEF helpers and `--check-system-cef` load CEF on demand. Runtime/backends remain
  statically included in one executable; no bundled backend DLLs are extracted.
- Imports are resolved once before backend initialization. Subsequent calls use
  a tail jump, with no per-call symbol lookup or loader lock. Native build logic
  and final ELF checks have dedicated modules; Node-API exports are also checked.

## Arch Linux / CachyOS packages

`dnr` and `dnr-bin` require only `glibc`, `gcc-libs` and `zlib` at runtime.
Install `cef` **and** `gtk3` for CEF windows, or `webkit2gtk-4.1` for WebView.
These are optional runtime dependencies; the dual source build still requires
both GUI stacks. Single-backend package dependencies remain mandatory.

| Asset | Contents |
| --- | --- |
| `dnr-0.3.1-1-x86_64.pkg.tar.zst` | Dual runtime with optional GUI dependencies |
| `dnr-cef-0.3.1-1-x86_64.pkg.tar.zst` | Directly linked CEF-only runtime |
| `dnr-webview-0.3.1-1-x86_64.pkg.tar.zst` | Directly linked WebView-only runtime |
| `dnc-0.3.1-1-x86_64.pkg.tar.zst` | Standalone packager |

The corresponding `-bin` recipes verify release checksums and regenerate package
metadata. Choose one runtime; install dnc independently.

## Validation

Native Linux x86_64 / CachyOS / KDE Wayland validation covers missing GUI libraries,
real CEF/WebView windows, backend fallback, page bindings, native window closing,
Node-API/FFI, caches and DNP applications. The headless missing-library regression
also runs in the dual release build. See `VALIDATION.md` and `docs/PERFORMANCE.md`
for the measurements and exact scope. Process crashes cannot trigger fallback.
The release workflow publishes Linux x86_64 packages; macOS is not newly validated
in this patch release.
