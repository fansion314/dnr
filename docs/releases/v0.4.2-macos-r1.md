# dnr v0.4.2 macOS revision 1

This macOS repair keeps the tool version at 0.4.2 and the existing v0.4.2 tag
unchanged. The combined `dnr-0.4.2-macos-arm64-r1.tar.gz` contains WebView dnr
and the repaired dnc. Homebrew uses `revision 1` so existing installations can
upgrade normally:

```sh
brew tap fansion314/dnr https://github.com/fansion314/dnr.git
brew update
brew upgrade fansion314/dnr/dnr
```

New macOS bundles default to finding dnr in the inherited PATH. If it is absent,
the launcher tries stable Homebrew paths, `/usr/local/bin/dnr`, and
`~/.local/bin/dnr`, covering Finder's restricted PATH. Explicit absolute
`macos.runtimePath` values remain strict pins and never silently switch runtimes.
Argument boundaries, cwd and the supervised process lifetime are preserved.

Existing apps contain their old launcher and must be repackaged with the repaired
dnc to get automatic discovery. Applications that explicitly pin their runtime,
including installers using a hash-specific runtime, retain that setting.

Local validation before publication passed workspace tests, strict Clippy,
native launcher discovery and supervision tests, and a real Homebrew install
whose generated `.app` found the installed runtime with `PATH=/usr/bin:/bin`.
Actions performs the complete release rebuild and repeats those checks before
publication. The archive's `BUILD-INFO.json` records its actual source commit.

Installation remains prebuilt-only, for macOS 15+ ARM64. Executables keep basic
ad-hoc signatures without Developer ID signing or notarization. Original
v0.4.2 assets, the tag, and Linux packages are not replaced by this revision.
