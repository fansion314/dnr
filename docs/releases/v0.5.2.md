# DNR v0.5.2

macOS windows now keep their centered position when their requested or saved
size is applied during native creation. An explicit window position still takes
precedence, and later `setSize()` calls retain the existing position.

`dnr cache clean --path` accepts Shell style path patterns. Quote patterns so
the shell passes them to dnr: `*`, `?` and `[]` match within one path segment;
`**` can cross directories. Paths without wildcards remain exact matches.
`--path-regex` remains available for existing scripts.

`dnr cache clean --trace` checks every cached source path against the current
v4 `.dnp` or full installation descriptor. It removes caches for missing
sources and old content identities. Existing sources that cannot be validated
are reported as `skipped-unreadable` and kept for manual inspection. `--dry-run`
previews the candidates; active
cache leases still prevent removal.

DNP format remains v4. Package contents and runtime permissions are unchanged.
