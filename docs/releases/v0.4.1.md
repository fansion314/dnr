# dnr v0.4.1

This release fixes desktop close/tray behavior and Node numeric open flags,
and adds explicit window-close policies. DNP remains format v4: existing v4
packages stay compatible; v1-v3 packages still require repackaging.

## Desktop behavior

- Native close requests now reach a cancelable JavaScript `close` event before
  destruction. Applications can call `preventDefault()` and hide the existing
  window without losing page state.
- dnr adds `closeBehavior: "hide" | "destroy"` (default: `"destroy"`),
  `setCloseBehavior()`, `getCloseBehavior()`, and `destroy()`. These are downstream
  extensions, not APIs from the pinned upstream Deno Desktop.
- **Behavior change:** `BrowserWindow.close()` also dispatches a cancelable close
  event before applying its policy. Use `destroy()` to bypass that event.
  Existing WebGPU native-handle safety still takes precedence over destruction.
- Linux AppIndicator activation is forwarded to the tray click handler when the
  loaded library exposes its `activate` signal. Plasma/KWin X11 6.7.5 with
  Ayatana 0.6.0 passed actual left-click restoration of Songjian's retained page.
  Xfce is outside the current support target; its menu-first fallback remains.
- dnc's macOS launcher supervises the shared runtime process, preserving native
  bundle/tray identity and forwarding signals while collecting the exit status.
  Rebuild thin macOS apps with dnc 0.4.1 to receive that launcher change.

## Node compatibility

Standalone numeric `O_EXCL` is preserved as an OS flag instead of becoming
exclusive creation. Only `O_CREAT | O_EXCL` maps to exclusive creation.
Linux syscall tracing confirms the distinction; no real block-device flashing
or exclusive-device lifetime validation is claimed.

## Validation and distribution

macOS ARM64 and native Linux x86_64 WebView testing covers Node-API/FFI, VFS,
cache behavior, numeric open flags, and close-policy regressions. Linux has
20 explicit runtime tests plus eight window-manager close cases. Real Songjian
checks on macOS and Plasma X11 confirm native close hides the existing page,
restoration retains its state, and the app can exit normally.

GitHub Actions builds and checks the dual, CEF-only, WebView-only, and standalone
dnc Arch/CachyOS x86_64 packages before publishing assets and checksums.
This release preparation does not claim new CEF, Wayland, GPU, or audio GUI
acceptance. macOS ARM64 binaries are built and installed locally.
