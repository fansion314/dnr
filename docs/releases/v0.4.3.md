# dnr v0.4.3

This release automatically remembers application zoom and fixes macOS raw-device
flush errors affecting Etcher. DNP remains format v4; existing applications are
compatible and receive these runtime fixes without repackaging.

## Persistent application zoom

- Native Cmd/Ctrl `+`, `-`, `0` shortcuts and `Deno.desktop.setZoomFactor()` now
  save the application multiplier immediately and restore it before application
  code runs on the next launch.
- Settings use the existing appId identity, so moving or upgrading a DNP and
  switching between a DNP and its full installation preserve the preference.
  Plain scripts use their canonical entry path.
- System display scaling and the user-wide `dnr zoom` factor remain independent.
  Resetting application zoom to 1 preserves the user-wide factor.
- An application that unconditionally calls the setter at startup overrides the
  restored value; applications should read the getter instead of reapplying a
  default. Configuration write errors warn without interrupting the application.

## macOS raw-device synchronization

Raw/block device `sync` and `datasync` operations now use POSIX `fsync` on macOS,
matching Node/libuv behavior. Regular files retain Rust's stronger `F_FULLFSYNC`
semantics. This fixes `Inappropriate ioctl for device (os error 25)` when Etcher
finishes validation and flushes a raw disk. Both synchronous and asynchronous
Deno and Node compatibility paths are covered.

## Packages and verification

Linux Release assets are the directly installable Arch packages
`dnr-0.4.3-1-x86_64.pkg.tar.zst`, `dnr-cef-0.4.3-1-x86_64.pkg.tar.zst`,
`dnr-webview-0.4.3-1-x86_64.pkg.tar.zst`, and `dnc-0.4.3-1-x86_64.pkg.tar.zst`.
Choose one runtime variant and install with `sudo pacman -U <package>`.
AUR `-bin` recipes still use makepkg to produce their own package identity.
The macOS ARM64 archive `dnr-0.4.3-macos-arm64.tar.gz` contains both tools.

Before release, native debug runtimes passed headless zoom persistence tests on
macOS ARM64 and Linux x86_64. Real shortcut and window-restart tests passed on
macOS WebView, Linux WebView, and Linux system CEF under KDE X11 software rendering.
The macOS fix passed a disposable raw disk image regression and Etcher's actual
write/verify worker; no physical user disk was written during automated tests.

Release Actions rebuild and test the macOS and three Linux runtime variants.
Their final status, checksums, and public-download installation checks are
recorded in Actions and the Release assets. See
[zoom behavior](https://github.com/fansion314/dnr/blob/v0.4.3/docs/ZOOM.md) and
[validation details](https://github.com/fansion314/dnr/blob/v0.4.3/VALIDATION.md).
