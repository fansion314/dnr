# 性能审查与复测

本轮聚焦应用执行路径，不改变 `.dnp` 格式、默认缓存预算或桌面生命周期。
测试环境和测量结果见 [VALIDATION.md](../VALIDATION.md)。

## 已优化的热点

| 路径 | 原实现 | 当前实现 |
| --- | --- | --- |
| `integration/rt/dnr.rs` 的 VFS 建树 | 每遇到目录就递归扫描整个扁平索引，约 O(目录数 × 条目数) | 逆序遍历已排序的索引，自底向上组装，每个节点处理一次；仍有 BTreeMap 查找及目录内排序成本 |
| `crates/package/src/lib.rs` 的缓存命中 | `VecDeque::retain` 扫描全部缓存条目，再移至队尾 | HashMap 条目保存前后索引，平均 O(1) 提升和淘汰；最近一次命中的条目无需重连 |
| `integration/deno.patch` 的目录合并 | 每个磁盘条目线性扫描已有条目；metadata 路径还会额外枚举一次磁盘 | HashSet 查重，metadata 路径复用已取得的 ZIP 元数据；每次调用只枚举一次磁盘 |

VFS 仍保留目录排序、ZIP 优先、只读和符号链接语义。缓存仍按内容字节数淘汰，
打开的文件句柄通过 `Arc` 保留数据；不因 LRU 淘汰导致已有读取者的数据失效。
本轮未新增依赖或 unsafe 代码。

## 可重复基准

```sh
# 包索引读取、100 / 10000 个驻留文件下的缓存命中
cargo run --release -p dnr-package --example performance

# 加入真实 runtime 启动与 Deno/Node 目录枚举
DNR_BIN="$PWD/dist/dnr" cargo run --release -p dnr-package --example performance
```

宿主配置 sccache 时保持启用。如果 Cargo 缓存了先前沙箱中的 `rustc -vV` 权限错误，
可以在已获准访问缓存的构建环境中设置 `CARGO_CACHE_RUSTC_INFO=0` 重新探测；这不关闭 sccache。

基准在临时目录生成 Zstd level 6 ZIP，各指标预热一次，记录后续 7 次样本的中位数。
测试数据生成与缓存预填充不计入计时；结束后清理临时文件。

- 索引与启动：2,500 个模拟 npm 包目录，每个 4 个小文件；另有入口及隐式父目录。
  `Package::open` 得到 12,502 个节点。启动计时包含新进程、VFS、V8、模块执行及退出。
- 缓存：预先读取 100 或 10,000 个文件，再通过 `read_index` 循环命中 20,000 次。
  该指标隔离缓存维护成本，不含路径解析、JS API 或文件内容复制。
- 目录合并：10,000 个 ZIP 文件与 5,000 个磁盘文件，其中 2,500 个同名。
  每次样本调用 20 次 Deno `readDirSync` 和 20 次 Node `readdirSync`，校验结果为 12,500 项。
  使用脚本内 `performance.now()`，不把进程启动算进目录枚举时间。

比较前后版本时，对两份源码使用同一个基准程序、相同 release 配置和同一台机器。
这些是暖文件系统缓存下的合成负载，不代表所有应用同比提速，也不代表冷启动或 Linux 实测。
基准不设置硬性耗时断言，以免把系统负载抖动当成正确性失败。

## 审查后保留的成本

- 包内不同文件的解压目前仍由同一个 Mutex 串行化；缓存命中也要获取此锁。
  这保护共享 ZIP 游标，并避免同一可缓存条目并发重复解压。进一步优化需要独立读取游标、
  每条目的并发合并及错误重试设计，先用真实多 Worker 负载确认锁竞争。
- `read_file_all` 接入 Deno 的 `Cow<[u8]>` 时仍会复制缓存中的 `Arc<[u8]>` 内容；
  JS 返回值也有自己的内存成本。减少复制需要配合上游所有权接口，不能直接借出可淘汰数据。
- TS 转译和 CJS 分析仍在运行时完成，dnc 仍只打包。没有引入持久转译缓存或改变包内容。
- 桌面 worker 在事件循环已空闲但窗口/托盘仍存活时，保留 10 ms 等待后复查的逻辑。
  改成事件通知需覆盖所有关闭、托盘与退出路径，并测量实际空闲 CPU；本轮未修改生命周期。
- ZIP 读取增加 `BufReader` 的试验在当前负载上未显示收益，已撤回。

## 正确性验证

新增测试通过一个简单的参考 LRU 模型检查 5 种预算、每种 2,000 次访问，覆盖命中、淘汰、
零字节文件、超预算文件和持有引用的读取者；损坏 CRC 的文件仍按需报错且不进入缓存。
原生回归另覆盖大目录树、前缀相近的目录名、Unicode、空目录、符号链接及两层目录合并。
这些测试与原有的 Node 插件、Worker、TS/CJS、退出等原生测试一并执行。
